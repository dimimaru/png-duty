เชื่อม Google Sheets

ใช้ Google Sheets ที่เปิดอ่านสาธารณะ และ API Key ซึ่งจำกัดการใช้งานเฉพาะเว็บไซต์นี้

การตั้งค่าเก็บในเบราว์เซอร์ของเครื่องนี้เท่านั้น API Key ที่ใช้ในเว็บสาธารณะไม่ใช่ความลับ จึงต้อง Restrict API และ HTTP referrer ใน Google Cloud
