# แพตช์ v4 — วันหยุด / OPD เฉพาะทาง / SMC

อัปโหลด app.js, sheets.js, style.css, sw.js และ opd.js ไว้ราก repo แทนไฟล์เดิม (opd.js เป็นไฟล์ใหม่)
ใช้ร่วมกับเวอร์ชัน v3 เดิม ไม่ต้องเปลี่ยน config.js หรือ API key
หลังอัปโหลดเสร็จให้โหลดเว็บใหม่เพื่อรับ service worker รุ่น v4

## วันหยุด
- หน้าเวร: เสาร์–อาทิตย์ + วันที่คอลัมน์ AP ของ ALL เวรระบุ holiday
- หน้า OPD และ SMC: วันหยุดข้างต้น + ข้อยกเว้นเฉพาะ OPD จากแท็บ OPD Holidays
- ทุกวันหยุด หน้า OPD เว้นข้อมูลคลินิก รวม GP และ SMC
- รายเดือน GP เว้นข้อมูลในวันหยุดด้วย
- หน้าเวรยังใช้เวรนอกเวลาของวันนั้น ไม่ใช้ข้อยกเว้นเปิด/ปิด OPD ไปเปลี่ยนตารางเวร

## เพิ่มวันหยุดกะทันหันเฉพาะ OPD
สร้างแท็บชื่อ OPD Holidays ใน Google Sheet เดิม (ไม่ต้องสร้างหากไม่ใช้)
ใส่หัวตารางแถว 1:
A: date | B: state | C: note
แถวถัดไปใช้วันที่แบบ YYYY-MM-DD หรือเซลล์วันที่จริง
state = CLOSED เพื่อปิด OPD หรือ OPEN เพื่อเปิดในวันธรรมดาที่ชีตหลักระบุ holiday
เสาร์–อาทิตย์ยังปิดเสมอ
ตัวอย่างรูปแบบ (เป็นวันสมมติ ไม่ใช่ประกาศวันหยุดจริง):
2026-11-02 | CLOSED | ตัวอย่างวันปิด OPD เพิ่ม
หนึ่งวันหนึ่งแถว ลบแถวเพื่อยกเลิกข้อยกเว้น
คอลัมน์ AP ใน ALL เวรยังใช้เพิ่มวันหยุดได้ตามระบบเดิม

ระบบตรวจวันหยุดจากชีตเมื่อเปิดเว็บ/กลับมาออนไลน์/กดรีเฟรช และประมาณทุก 5 นาทีขณะเปิดเว็บ
รายการข้อยกเว้นที่อ่านสำเร็จเก็บในเครื่องเพื่อใช้ Offline
หากอ่านชีตไม่สำเร็จจะคงรายการล่าสุด ไม่ล้างรายการวันหยุดที่เคยบันทึกไว้
นี่ไม่ใช่การติดตามประกาศรัฐบาลอัตโนมัติ: ต้องมีผู้แก้ชีตต้นทางก่อนเว็บจึงจะรับวันหยุดใหม่ได้
ยังไม่ได้เชื่อมแหล่งประกาศรัฐบาลที่ยืนยันและรองรับการดึงข้อมูลอัตโนมัติ

## ตาราง OPD
ข้อมูลเฉพาะทางถอดจาก OPD Spec. PNG Hosp..pdf หน้า 2–4 ไม่อ่านหน้าที่ซ้ำ
opd.js เก็บกติกาตารางประจำสัปดาห์ จึงแก้รายชื่อ/คลินิกในไฟล์นี้เมื่อประกาศตารางใหม่
แพทย์หมุนเวียนไม่แสดงชื่อสมมติ
GP ยังอ่านจาก Google Sheet เดิม อยู่บนสุด
SMC เป็นแท็บย่อย มีตารางรายสัปดาห์ตามแบบเอกสาร เลื่อนแนวนอนได้บนมือถือ
นับสัปดาห์เป็นครั้งที่ 1,2,... ของวันนั้นในเดือน เช่น วันศุกร์ครั้งที่ 1 และ 3 เป็น Warfarin
วันศุกร์ครั้งที่ 2 และ 4 เป็น Cardio; ครั้งที่ 5 ไม่แสดงสองคลินิกนี้ (DM ยังแสดงตามตาราง)
HIV เด็กวันพุธครั้งที่ 1; Lactation/High-risk infant วันพุธครั้งที่ 2–5
ข้อจำกัดของคลินิกพุธพักใจและ NeuroSx ใส่หมายเหตุกำกับแล้ว
ตาราง PDF ไม่ระบุวันเริ่มใช้และข้อยกเว้นรายวัน จึงต้องตรวจสอบเมื่อมีการประกาศเปลี่ยนแพทย์/คลินิก

## ตรวจสอบ
ผ่านการตรวจ syntax และทดสอบกติกาด้วยข้อมูลตารางเวรที่แนบ:
วันหยุด/เซลล์รวม, MED/PED ไม่แสดง consult ย่อยวันหยุด, Forensic fallback,
1st call บรรทัดเดียว, OPD นอกเวลาช่องบ่ายและดึกว่าง,
กติกาสัปดาห์ที่ 1/2/3/4/5, ตาราง SMC, ข้อยกเว้นวันหยุด, สีชื่อไม่ซ้ำ
ยังไม่ได้ทดสอบการแสดงผลบน Safari/iPhone จริงหรือ API กับ key ของเครื่องผู้ใช้
